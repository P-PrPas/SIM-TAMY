# Evidence explorer (FR-SCR-05, FR-DEB-03, FR-GB-01)

The completed Glass Box now exposes every rubric item, its original engine result,
earned/possible points, competency, critical flag, findings and document locators.
Event evidence links filter the completed conversation to that learner turn;
reset restores all messages. Missing evidence, history, or references stays explicit.
Rubric and engine versions identify the assessment used.

References are content-provided sources, not a claim of expert approval. Instructor
overrides retain their separate effective summary. The existing authenticated
completed-session reader is reused; no extra active-session data is exposed.

Validation: component and report tests, TypeScript, lint, and mobile report journey.
