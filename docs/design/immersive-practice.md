# Immersive practice

User-authorized extension of FR-FAM-01..03, 2026-10-18. References and design
hypotheses: [engagement research](../research/chat-engagement-patterns.md).

## Conversation stage and activity

Original, local SVG illustration uses the existing cream/brown/gold tokens.
The stage displays only the current public chapter and speaker. It is collapsible
and compact at 360px; its short scene-change movement respects reduced motion.
The family rooms, clinical chat and recorded examples share this presentation.
No animation or character expression encodes correctness, risk or hidden facts.

Family choices use native radio inputs followed by an explicit commit button.
Selection is local and editable until submission. A new room/state version resets
the selection. Existing optimistic delivery, retry IDs, locking and scoring remain
unchanged. No new task assignment, clinical instruction or assessment rule is inferred
from the illustration. The activity commits an existing content-authored choice.

## Shared journal, chapter beats and storyboard

Every room shows its committed public choices with actual role attribution in a
collapsible journal. It is a record of statements, not an assertion of mutual
consent, online presence or a diagnosis. It reads the same room transcript on each
device and survives refresh. No private brief or draft selection is shared.

A changed public chapter opens an inline continuation beat. The learner controls
when to continue; no timer or additional decision is submitted. Background props
vary decoratively across the already-public chapter list, never by correctness.

After completion, a navigable storyboard joins each recorded choice and reply to
its engine finding by turn index and to its actual source IDs. Starting again
returns to enrollment for a new room; the original room/events are not rewritten.
Clinical report timeline cards also gain visual sequence markers using existing
event data; parent profiles are not applied to clinical learners.
