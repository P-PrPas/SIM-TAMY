# Family experience design

Extends FR-FAM-01/02/03 on top of PRs #78–80. Presentation only; story rules,
clinical content, role isolation and report calculations stay unchanged.

Palette: existing canvas `#fcfaf6`, ink `#302b25`, brand brown `#47351f`,
gold `#efbd51`, soft gold `#f8edcf`, and white `#ffffff`. Typography: the existing
local Noto Sans Thai; spacious body text, deliberate heading weights and readable
line lengths. No new font, component package or external image dependency.

Two layouts considered:

    Entry:  [course navigation] [story + family illustration]
            [role selection / start] [join invitation / learning outline]
    Room:   [role + progress] [private brief | current conversation + choices]
            [previous exchanges, on demand] [evidence report after completion]

The entrance is editorial and welcoming; the room is task-focused. A repeated
hero illustration during play would distract, so the active view uses a compact
heading. New dialogue remains visible while older exchanges can be expanded.
All motion must respect reduced-motion preferences. Feedback counts are actual
activity observations, never promotional metrics or validated readiness claims.
Mobile navigation uses four balanced destinations, and the logo link takes its
accessible name from its visible text. Only the three-chapter journey displays
the chapter overview; Co-op and Bridge emphasize the current conversation.

References inspected: [Skooldio](https://www.skooldio.com/) for learning hierarchy,
[HeroInspo](https://heroinspo.com/#galleri) for a focused story introduction,
[Navbar Gallery](https://www.navbar.gallery/) for grouped destinations, and
[CTA Gallery](https://www.cta.gallery/) for clear action priority. These are
directional references; illustration, layout and copy are original to SIM-TAMY.
