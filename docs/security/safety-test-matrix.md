## Gaps (recorded, not fixed)

- Case 1-2: there is no explicit scope-boundary message ("I cannot diagnose or give doses"). The behavior is a neutral
  in-character line plus validator blocking of model output. Adding a boundary message needs Content-team wording
  (`TODO(content):`); it is not hard-coded here.
- Case 4: misspelling robustness with a real model is not measured; only deterministic fallbacks are tested.
- Case 8: needs a product decision (a `Retired` status that hides a case from new sessions while keeping old reports readable).
